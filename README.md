# Hi, I'm Eli! 👋

Trying to do a bit of everything, one project at a time. Lately that's
creative coding: camera- and music-driven visuals and sound for DJ sets, all
in Python.

## What I'm building

| Project | What it does |
|---|---|
| [**ascii-trails**](https://github.com/elikennie/ascii-trails) | Anything moving in front of a webcam (DJs, dancers, a jumping crowd) leaves fading trails of ASCII symbols over the live feed. |
| [**chimes**](https://github.com/elikennie/chimes) | Camera motion tracking that plays wind chimes, through a built-in synth or into FL Studio over MIDI. |
| [**master-viz**](https://github.com/elikennie/master-viz) | An iTunes-classic style visualizer for a DJ master out (rekordbox / FL Studio), synced to the beat with Ableton Link. |

**Tools I use:** Python · OpenCV · NumPy · MIDI · FL Studio · rekordbox · Ableton Link
